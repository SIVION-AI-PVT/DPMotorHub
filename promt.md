DP MOTORHUB — FULL WEBSITE DESIGN BRIEF
═══════════════════════════════════════════════════════

1. PROJECT OVERVIEW
Design a complete, premium e-commerce website for "DP Motorhub" 
(dpmotorhub.com) — a specialist online retailer of genuine and 
aftermarket BMW M-Series performance parts. Customers are BMW 
enthusiasts and owners of M-cars and M-Sport variants looking for 
engine, brake, suspension, exterior, wheel, and interior parts. 
The brand competes on authenticity, technical expertise, and fast 
fulfillment — not on being the cheapest option.

2. DESIGN PRINCIPLES
- Precision German engineering meets motorsport culture.
- Confident, technical, minimal — never loud or cluttered.
- Every element should feel intentional, like it was engineered, 
  not decorated.
- Premium retail polish (think boutique performance-parts brand), 
  not a generic auto-parts marketplace.
- White space is a design tool — let content breathe.

3. COLOR SYSTEM
Base palette (used for ~90% of the interface):
- Near-black charcoal: #0B0B0D — primary background for hero/dark 
  sections, primary button fill, header text on light backgrounds
- Pure white: #FFFFFF — primary background for content sections, 
  text on dark backgrounds
- Graphite gray: #1C1C1F — card backgrounds within dark sections, 
  secondary surfaces
- Light gray: #F2F2F3 — alternating section backgrounds, disabled 
  states, input field fills
- Mid gray: #6B6B70 — secondary/muted text, placeholder text, 
  captions

Signature accent — BMW M tri-stripe (use sparingly, as a brand 
signature, never as a large fill):
- M Blue: #008AC9
- M Purple: #2B115A
- M Red: #F11A22
Approved uses ONLY: a 3–4px horizontal tri-stripe beneath the 
navbar logo; an underline reveal on primary button hover; small 
diagonal accent behind the hero headline; a thin left-border on 
"M Performance" product badges; active-state underline on nav 
links. The three colors should always appear together as a set 
(never used individually as a random accent) to preserve the 
brand reference. Never use the stripe as a full-width banner or 
section background — that reads cheap, not premium.

4. TYPOGRAPHY
- Headings: bold, geometric, technical sans-serif (style close to 
  Inter Bold / Neue Haas Grotesk Bold / Suisse Int'l). Tight 
  letter-spacing on large headlines, uppercase for eyebrow labels 
  and nav items.
- Body: same family, Regular/Medium weight, comfortable line-height 
  (1.5–1.6) for readability.
- Scale: H1 56–64px (hero), H2 36–40px (section titles), H3 22–24px 
  (card/product titles), body 16px, small/caption 13px.
- Numbers (prices, part numbers) in a slightly tabular/monospaced 
  treatment for a technical feel.

5. GRID & SPACING
12-column responsive grid, max content width ~1280px, generous 
section padding (96–120px vertical on desktop, 48–64px mobile). 
Consistent 8px spacing scale throughout.

6. IMAGERY DIRECTION
High-contrast, dramatically lit product photography on dark or 
neutral backgrounds — not flat catalog-style white-box shots. 
Hero imagery: close-up detail shots of M-car components (brake 
calipers, carbon fiber trim, engine bay) rather than full 
dealership-style car shots — this is a parts store, not a 
dealership. Avoid generic stock photography of unrelated cars.

7. ICONOGRAPHY
Thin-line, technical/engineering-style icons (not rounded or 
playful) for category tiles, trust badges, and UI controls — 
consistent stroke width throughout.

h) NEWSLETTER / CTA BANNER — Dark section, bold line inviting

11. SHOP / CATALOG PAGE
═══════════════════════════════════════════════════════

  code checkboxes — E9x, F8x, G8x etc.), Category, Price range

  grid/list view toggle

  tri-stripe accent), part name, compatible models, price, 
  quick-add button on hover
- Pagination or "Load more" at bottom
- Empty state: illustration + "No parts match your filters" + 
  reset button

16. COMPONENT STATES
═══════════════════════════════════════════════════════
- Primary button: solid charcoal fill, white text, on hover fills 
  slightly lighter + tri-stripe underline animates in
- Secondary/outline button: transparent fill, charcoal border, 
  inverts on hover
- Input fields: light gray fill, thin border, blue-tinted focus 
  ring (use M Blue #008AC9 for focus states only)
- Cards: subtle border by default, soft shadow + slight lift on 
  hover
- Badges: small pill shape, tri-stripe left border for "M 
  Performance" tag, solid gray for "In Stock", solid red-tinted 
  for "Low Stock"

═══════════════════════════════════════════════════════
17. RESPONSIVE BEHAVIOR
═══════════════════════════════════════════════════════
Design for desktop-first (1440px), then adapt: tablet (768–1024px) 
collapses sidebar filters into a slide-over drawer and reduces 
grid to 2 columns; mobile (375–428px) stacks everything to a 
single column, hero text shrinks to ~32–36px, sticky bottom bar 
with "Add to Cart" on product pages.

═══════════════════════════════════════════════════════
18. ACCESSIBILITY
═══════════════════════════════════════════════════════
Maintain WCAG AA contrast ratios — body text on white/charcoal 
backgrounds must stay clearly legible; never place body text 
directly on the tri-stripe accent colors.

═══════════════════════════════════════════════════════
19. AVOID
═══════════════════════════════════════════════════════
Beige/brown dealership aesthetics, stock-photo-heavy generic 
feel, rainbow/candy use of the M stripe across large areas, 
cluttered multi-column homepages, tiny illegible price text, 
rounded "friendly" iconography that undercuts the technical/
premium tone, drop shadows that feel dated/skeuomorphic.

OUTPUT: Full responsive design system covering Home, Shop/Catalog, 
Product Detail, Cart, About, and Contact pages, desktop and mobile 
variants, consistent with the design principles and color/type 
system above.
